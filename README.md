# socdoc.tech

Portafolio personal de Santiago Ospina Calle. Sitio estático bilingüe (es/en) construido con [Astro](https://astro.build), Tailwind CSS y React para los componentes interactivos.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Despliegue

El despliegue a GitHub Pages es automático en cada push a `main` vía `.github/workflows/deploy.yml`.
